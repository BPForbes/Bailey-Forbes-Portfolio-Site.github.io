# AGENTS.md

Instructions for coding agents working in bailey-forbes.com, the static portfolio
of Bailey Forbes. This file is canonical. `CLAUDE.md` imports it, so Claude Code and
other agents read the same rules. Where a folder has its own instruction file, that
file adds to these rules and points back here.

## Instruction files and what they govern

| File | Governs | Read it when you touch |
|---|---|---|
| `AGENTS.md` (this file) | The whole repository | Anything |
| `CLAUDE.md` | Claude Code specifics; imports this file | Hooks, settings, the UI/UX skill |
| `DESIGN.md` | The design rule set (R01–R30) and this site's implementation record (Part B) | Layout, tokens, components, copy, motion |
| `src/AGENTS.md` (+ `src/CLAUDE.md`) | TypeScript sources and the build | `src/**` |

| `contact-worker/AGENTS.md` (+ `contact-worker/CLAUDE.md`) | The contact API | `contact-worker/**` |
| `docs/agents/multi-repo.md` | How the other project repositories connect | Project data, embeds, notify, sync |
| `docs/agents/deployment.md` | GitHub Pages, Cloudflare Workers, the contact API | Workflows, Wrangler config, `CNAME`, `.assetsignore` |
| `docs/agents/keyquorum.md` | KeyQuorum's Cloudflare layout and kq file formats | Anything about KeyQuorum |
| `tools/README.md` | The audit and contrast scripts | Layout or token changes |

Instruction files refer to each other in both directions. Each one ends with a
"Related instruction files" section. When you add a reference from A to B, add the
reverse reference from B to A in the same change. `tests/instruction-links.test.mjs`
(run by `npm test`) fails on any one-way reference, on a missing `CLAUDE.md` beside an
`AGENTS.md`, and on a file that refers to no other.

## What this repository is

A static site. Plain HTML in `home/` and `projects/`, one stylesheet in `css/styles.css`,
TypeScript in `src/` compiled to `js/` and bundled by `tools/build.mjs`. There is no
server, no analytics, no build step beyond `tsc` and esbuild, and runtime requests to third parties only for Google Fonts, the embedded project labs, and the contact form (Cloudflare Turnstile and the contact API). Every behaviour is
client-side and must work with scripting off, at least in its final state.

The site presents Bailey's work in five projects. Four have their own repositories; see
[`docs/agents/multi-repo.md`](docs/agents/multi-repo.md).

## Hard rules

1. **Every factual claim must trace.** A number, date, version, or quotation on the site
   comes from the résumé, from public git history, or from a project's own docs. If you
   cannot point to the source, do not write it. Do not invent testimonials, metrics, or
   awards (DESIGN.md R15, R16).
2. **Never hand-edit generated files.** They are written by the sync job or the build:
   `data/project-metadata.json`, `data/commit-bodies.json`, `src/generated/projectMetadata.ts`,
   `modules/**` (regenerated by `npm run build`), `js/**`, `css/vendor/**`. Change the
   source and rebuild. `modules/` is tracked, so a source change that alters it must
   commit the regenerated files too.
3. **Curated copy belongs to a person.** `src/data.ts` and the project HTML are written by
   Bailey. Do not rewrite his prose to tidy it. Change copy only for control labels, state
   messages, and source attribution, unless he asks for more.
4. **No secrets in the tree.** Not in source, not in `.env`, not in a comment, not in a
   test fixture. Worker secrets and the Resend key are set outside the repository. The
   repository root is published by GitHub Pages (see Deployment below), so treat every
   file as public.
5. **Work on a branch and open a pull request.** `main` is protected by a ruleset that
   requires a pull request. Do not push to `main`. The metadata job is the only automation
   allowed past the rule, through its deploy key.
6. **Respect the security boundaries.** The notify workflow holds a token that can
   dispatch to this repository; pin any caller to a commit SHA, never `@main`. Keep
   workflow `permissions` minimal. Never interpolate `${{ }}` values into a shell script
   that holds a credential.
7. **Non-negotiable accessibility.** WCAG 2.2 AA is the bar (DESIGN.md R25). Every
   interactive element needs a visible focus ring, a name, and a 24 × 24 px target at least.
   Motion must collapse to its final state under reduced motion (the OS setting or the
   Display control). Nothing may depend on hover alone.
8. **Keep the site readable with JavaScript off.** Reveal classes and counters are added
   by script; their absence must hide nothing.

## Commands

```bash
npm ci                                  # install (cached in the cloud hook)
npm run build                           # tsc --noEmit, then tools/build.mjs
npm test                                # node:test suite; runs the build first
node --test contact-worker/index.test.mjs
python3 -m http.server 4173             # local preview at http://localhost:4173/home/
python3 tools/contrast.py               # token contrast, all four renderings
NODE_PATH=$(npm root -g) node tools/audit-a11y.mjs   # rendered audit; needs the server running
npm run sync:metadata                   # refresh generated project facts (needs network)
```

`npm test` expects `modules/` to be current. Run `npm run build` first if you changed
anything under `src/`.

## Adding or changing a project

1. Add the project's entry to `scripts/project-sources.mjs` and its id to
   `PORTFOLIO_PROJECT_IDS` in the same file. An unknown id is rejected by design.
2. Add the project page under `projects/<id>/index.html`, following the existing pages.
3. If it embeds a live build, add the origin to `src/apps.ts`.
4. Ask the project's repository to notify the portfolio (see `docs/agents/multi-repo.md`).
5. Run the sync once by hand, then the checks above. Confirm the generated data appears
   and nothing is invented.

## Design

[`DESIGN.md`](DESIGN.md) is the rule set this site is built to. Read Part A (R01–R30) before
a visual change, and Part B for what this site actually does with them. The current
direction is a commit-log theme: a bento overview, a story strip, and a trunk. Keep the
Display control working. It exposes theme, contrast, motion, and text size.

The UI/UX Pro Max skill (below) is guidance. It does not override DESIGN.md.

## UI/UX skill set

The skill set is installed into `.claude/skills/` and is gitignored. Never commit it.

- In a cloud session it is installed automatically by `.claude/hooks/session-start.sh`
  (registered in `.claude/settings.json`). The hook also runs `npm install` and `npm run build`.
- Locally, install once with `npx -y ui-ux-pro-max-cli@latest init --ai claude`, or use
  the marketplace plugin (`/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill`,
  then `/plugin install ui-ux-pro-max@ui-ux-pro-max-skill`), or install for every project
  with `--global`.
- It provides seven skills: `ui-ux-pro-max` (search over styles, palettes, typography,
  UX guidelines, and 22 stacks), `design`, `design-system`, `ui-styling`, `brand`,
  `slides`, `banner-design`.
- Query the core search script from the project root:
  `python3 .claude/skills/ui-ux-pro-max/scripts/search.py "<query>" --domain ux`.
  Use `--design-system` for a new page direction, and `--domain` for a focused concern.

## Git and pull requests

- Branch from `main`. Use a descriptive branch name and keep one concern per branch.
- Commit messages say what changed and why. Do not put a model name in a commit message,
  pull request, comment, or any file in the repository.
- A pull request must pass `typecheck.yml`. Run `npm test` locally before you push.
- Do not open a pull request unless the user asks for one.

## Things that are easy to get wrong

- Pages publishes the entire repository root, so this file, `docs/`, and `CLAUDE.md` are
  public URLs. Keep them free of anything you would not publish.
- `.assetsignore` only affects the Cloudflare Worker, not GitHub Pages.
- `CNAME` is the custom domain for GitHub Pages. Do not change it.
- The lab iframes need cross-origin isolation headers set in the Cloudflare dashboard,
  not in this repository. If a lab stops attaching, check that before editing code.
- A notification with the wrong event type is silently ignored. The type must be exactly
  `portfolio-project-updated`.
- The contact form is not live until the sender domain is verified and the secrets are set.
  Do not describe it as working in copy.
