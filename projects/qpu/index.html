Language and compiler design

A custom quantum instruction language with its own TypeScript compiler, simulator, and browser workbench — forty commits in four days, running a nine-qubit, twenty-gate circuit live.

Why it exists

QPU began as a small Python script written while preparing a presentation on quantum hardware fingerprinting, a topic explored in research on securing NISQ-era cloud quantum computing. Understanding how a quantum computer's own noise and gate errors could be used to identify it meant first understanding how a quantum instruction actually executes — which is what the script became: a compiler and simulator, later rebuilt as a browser workbench so a circuit could be written, compiled, and run without a local Python environment.

What it is

BPForbes.QPU.github.io (8–12 Jun 2026, originally BPForbes.github.io) is a TypeScript compiler for the QPU process language plus an interactive circuit canvas, file tools, truth-table I/O, and a correction lab.

What the commits added

Workbench, June 2026. Forty commits in four days. AST backend and gate-placement validation; interactive workbench; hamburger navigation and .qpucir persistence; progress visualization and PDF docs on Pages; two-bit adder register/output-binding fixes; RESET hidden from UI; pi rotations; Circuit Correction Lab (first WebLLM, then local Ollama); .qpuio truth-table metadata; partial tables; per-file gate modules and a custom-gate engine.
