What it is

BPForbes.QPU.github.io (8–12 Jun 2026, originally BPForbes.github.io) is a TypeScript compiler for the QPU process language plus an interactive circuit canvas, file tools, truth-table I/O, and a correction lab.

What the commits added

Workbench, June 2026. Forty commits in four days. AST backend and gate-placement validation; interactive workbench; hamburger navigation and .qpucir persistence; progress visualization and PDF docs on Pages; two-bit adder register/output-binding fixes; RESET hidden from UI; pi rotations; Circuit Correction Lab (first WebLLM, then local Ollama); .qpuio truth-table metadata; partial tables; per-file gate modules and a custom-gate engine.
