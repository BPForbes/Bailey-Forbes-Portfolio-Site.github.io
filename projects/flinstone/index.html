Flinstone Kernel

A portable kernel built from first principles in C and Assembly. Hardware abstraction, filesystems, process control, and device I/O sit behind versioned subsystem contracts so a release can move without silently breaking the last one.

What it is

The public kernel repo opens 28 May 2025 as a C filesystem and shell. The resume dates the project to 2023; Flinstone-OS (7–10 Jul 2025) is the C++/QEMU sibling with a minimal TCP/IP stack and libsodium. The C line is the one that grew a versioning machine: version/entries, locked files, and GM=1 promotes onto main.

About 70 versioned contracts cover networking, storage, drivers, diagnostics, and identity. Backward compatibility is explicit — metadata and migration notes, not “we’ll fix the callers.” Four core releases on that policy are 4.0.0, 4.0.1, 4.1.x, and 4.2.0, after a 2.x/3.x train that installed the versioning itself.

How the system grew

Hosted filesystem, then a machine. February 2026 turns the shell into an OS sketch: ASM memory primitives, Facade/Strategy/Command file management, port I/O drivers, a thread-safe allocator, an embedded x86 VM (disk, timer, paging, snapshots), and an MLQ scheduler with real vs stub driver capabilities on x86-64 and AArch64.

Contracts before more surface. 3.3.0 (12 May) splits audit from command history and documents fs_jail. 4.0.0 (18 May) is the major bump: inheritable P0–P9 bundles (foundations through hardening). 4.1.0 wires identity — SQLite users, PBKDF2, login/su/sudo, elevation. 4.1.1 is a 50-issue hardening sweep. 4.2.0 (19 Jun) is the networking milestone.

Networking from the metal up. The 4.2.0 .ver file lists netdev, software loopback, Linux TAP, ARP, IPv4 LPM, ICMP, UDP, TCP shims, DNS, DHCPv4, IPv6/NDP, a Wi-Fi station contract, a multi-device chat/file server, and WSL portproxy hosting. Later PRs add 802.11ax, home-SSID join, macvlan LAN identity, and Dragonfly SAE for WPA3.
