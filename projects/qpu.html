Two repositories, one language

QPU (10 Jul 2025) is the language and Python engine: parse_command in qpu/ast.py, a cycle clock driven only by INCREASECYCLE, process compilation from text files, child processes, tokens, join/split, measure, and both primitive and derived boolean gates.

BPForbes.github.io (8–12 Jun 2026) is not a generic homepage — it is a TypeScript port of that compiler plus an interactive circuit canvas, file tools, truth-table I/O, and a correction lab. QPU-Sim on the account is an empty stub from the same July week; the real simulator is the Python tree.

What the commits added

Python, July 2025. Early work is adder correctness: OR-gate rewrite, SingleBitFullAdder, per-case tests, then two-bit and four-bit protocols. A divide-and-conquer four-bit adder is attempted, then reset to a linear approach, then rewritten so the four-bit adder depends on two second-level adders rather than four single-bit adders. In parallel: Hilbert logging, cycle/snapshot mechanics, a statevector backend, noise channels, and ID locking so process wrap-up treats IDs as ancilla (unlock, reset to |0⟩, pop, log).

Workbench, June 2026. Forty commits in four days. AST backend and gate-placement validation; interactive workbench; hamburger navigation and .qpucir persistence; progress visualization and PDF docs on Pages; two-bit adder register/output-binding fixes; RESET hidden from UI; pi rotations; Circuit Correction Lab (first WebLLM, then local Ollama); .qpuio truth-table metadata; partial tables; per-file gate modules and a custom-gate engine.
