KeyQuorum

Secure file sharing centered on hardware key sharing. A file’s data key — or any secret — can be split recursively into a tree. Unlocking means reconstructing that tree, not presenting a single token or password.

What it is

The README is unusually precise about status: the CLI covers the concept, quorum split/reconstruct is implemented in software, and USB tokens are still on the roadmap. That honesty matches the git pace. The repo is created 24 Aug 2026 and, within days, has a SQLite store, a guarded share schema, a CLI that prompts for secrets instead of taking them as arguments, and review passes that close deletion races and hash leaks.

A flat M-of-N quorum is the simplest tree. The interesting case is organizational: a company master key splits across departments, and a department share splits again across a team. tree --node A B finds the lowest common ancestor; reconstruct starts there. Bridges let independent employee and manager stores sign across a cut without merging private subtrees.

Features in the order they were added

Day one store. PR #2 lands the local SQLite schema and guards against unsafe share deletion and type confusion. The same day: password manager, expiring share links, password-locked files, then the keyquorum binary with file permission and path checks.

Registry and trees. 25 Aug adds generate/register/list, recursive splits, signature verification, export bundles, PIN unlock windows, and pin relock. Review PRs fix share-file validation, weak-key checks, and transaction cleanup.

Arena, LCA, PSS. 30–31 Aug: arena-allocated trees, LCA reconstruct, cross-branch bridges, PSS eviction, and private sign bridges between stores that do not share a canonical document.

Mailbox, then restraint. 1 Sep introduces an Axum mailbox with API keys and Swagger, immediately reverts it, then re-lands a hardened relay (merge, URL, store integrity). 2 Sep adds date-based TTL and a signed provider identity for minting customer keys — and drops network presence checks from the product. The mailbox is a sealed-envelope router; it never unwraps .kqpb packages.
